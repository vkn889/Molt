# Molt 0.9.1: Answer questions, see the diff

<p align="center"><img src="https://raw.githubusercontent.com/vkn889/Molt/main/docs/screenshots/app-icon.png" width="128" alt="Molt app icon"></p>

Two upgrades to answering your agents from the notch: Claude Code's questions now come to Molt, and every edit shows you its diff before you allow it.

## 💬 Answer Claude Code's questions in the notch

![Question in the notch](https://raw.githubusercontent.com/vkn889/Molt/main/docs/screenshots/notch-question.png)

When Claude Code asks you to choose ("Which storage should we use?"), the options drop down from the notch as buttons, with each option's description.

- **Click an answer** and Claude Code carries on.
- **Pick several** when the question allows it, or **type your own** answer.
- **Several questions?** They come one at a time, then go back together.
- Prefer the terminal? **Terminal** hands the question back, and it won't pop up in Molt again.

## 🔍 See the diff before you allow an edit

![Diff before allowing](https://raw.githubusercontent.com/vkn889/Molt/main/docs/screenshots/notch-diff.png)

When Claude Code wants to edit a file, the approval card shows exactly what changes: lines removed in red, lines added in green, with a little context and a +/− count. Multi-part edits show each part. A new file shows its contents, and rewriting an existing file shows what's different from what's there now.

## 🔧 Also

- If you connected Claude Code in 0.9.0, Molt updates its hooks the first time 0.9.1 starts. Nothing else in your Claude Code settings changes.
- Molt only updates hooks it installed itself, so a second copy of Molt can't take them over.

## 📦 Install

Download **Molt-0.9.1.dmg**, quit Molt, drag the new Molt to Applications, and open it.

> Molt is ad-hoc signed, not notarized. On first launch, right-click Molt and choose **Open**.

Requires macOS 13 or later · Apple Silicon and Intel
