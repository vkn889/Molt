# Molt 0.5.0: Your companion hub

Molt now opens to a customizable hub for your companion and everyday Mac controls.

## Companion-first interface

- Retro pixel-edged controls and a warm console-inspired palette.
- Bundled Shrikhand display typography, with its SIL Open Font License.
- A taller notch panel, flush top edge, rounded lower corners, and reduced-motion support.
- Companion customization, Chat, Today, Care, and Play at the top of the hub.
- Cards can be shown, hidden, and reordered.

## Music, weather, and Mac controls

- Music and Spotify playback controls and explicitly refreshed track information.
- Volume control and saved playlist links. Opening a playlist does not guarantee autoplay.
- City search and current weather from Open-Meteo with attribution.
- Wallpaper favorites, applying wallpapers to current desktops, and session-local restoration.
- Dock position, auto-hide, and icon size controls. Applying these restarts the Dock.
- Saved Scenes combine selected apps, playlist links, wallpaper, and focus time. Every run presents an action preview.

## Usage and morning postcards

- Opt-in foreground app observation with conservative idle and sleep exclusion.
- Separate Claude Code and Codex CLI process-running estimates; background runtime is not attention or billing time.
- Opt-in numeric usage imports from standard local Claude Code and Codex session folders.
- Codex cumulative usage is converted into increments; repeated Claude records are deduplicated by message ID.
- Reported costs where available, or approximate estimates from user-entered blended rates. No invoice or subscription-cost claim.
- Morning postcards summarize the previous day after 7 AM while Molt runs or on the next launch.
- Reports and CLI observations retain up to 30 days; imports are bounded and partial scans are labeled.

## AI connection

The visible AI setup is now **Connect to Ollama**. Provider and model-selection controls are removed from the user flow. The package no longer bundles the legacy managed runtime. Existing companion and organizational data are preserved.

## Verification and scope

The local suite passed 54 tests, with four optional integration tests skipped. New tests cover daily interval clipping, cumulative usage deduplication, malformed usage records, and rate calculations. Dark and light previews were rendered and reviewed, and the public weather endpoint returned the expected fields.

Live Automation permission prompts, real Music/Spotify playback, actual Dock/wallpaper mutations, and physical multi-display behavior require hands-on validation. These system changes were not applied to the development computer just to test the controls. Usage is partial observation while Molt runs, not Apple's Screen Time database. Local logs may be incomplete, absent, oversized, or stored outside the standard folders. Rates are user-configured estimates; cached creation is currently treated as ordinary input.
